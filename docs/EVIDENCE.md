# Evidence and limits

The website's saved harmony case contains 10 measures and 24 historical candidate harmonic events.
Only the first 12 events have applicant-confirmed human review. This is a case study, not an
independent accuracy evaluation. Score-input errors can propagate into interpretation and feedback.

Harmony, form and assignment feedback are separate product capabilities. Repository interface
examples are synthetic; no teacher/student data, student grades, private scores or production
analysis implementation is published here. Engineering test passes do not prove musical correctness.
